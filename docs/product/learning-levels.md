# Absolute beginner level

Dialog creation and conversation practice offer **Absolute beginner** before A1
(**Principiante absoluto** in Spanish). The stored/API code is `A0`, an internal
label for the app's entry level, not a new formal proficiency qualification.
Existing A2 defaults and saved levels remain unchanged.

This level favors very common concrete vocabulary, basic present-time phrases,
one idea at a time, and useful repetition instead of vocabulary variety. Aim for
2 to 5 words per sentence, allowing a few more when necessary for natural language.
Keep adult-appropriate, grammatical language. Requested dialog vocabulary is still
included even if it is harder; simplify the language around it.

Standard dialogs have 4 to 6 short lines; the explicit three-line option still
takes precedence. Scenario generation also selects simpler everyday interactions.
The level is saved with the dialog and available in dialog filters.

Both live and recorded-turn conversation modes use the level. Replies contain at
most two short sentences and favor one easy yes/no or either/or question while the
goal remains active. Closing, goal privacy, and the requirement to meet the goal
in the learning language remain unchanged. Conversation level is remembered in
the browser, like the other levels. Selecting a level also selects its default
speech speed: A0 uses Super slow, A1 uses Slow, and A2/B1 use Normal. The learner
can then override speed manually; the selected speed is remembered on return.
Without a saved speed, use the saved level's default. Changing level again
applies the new level's default speed. Goal difficulty remains separate; this
does not regenerate or simplify an existing goal.
