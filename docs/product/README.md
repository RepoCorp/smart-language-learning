# Product

This directory contains durable product knowledge for Smart Language Learning.

Start with the [learning glossary](learning-glossary.md) for shared conceptual
definitions of items, words, phrases, patterns, strategies, exercises, and evaluations.

Use it for principles and constraints that describe what the product is trying to achieve and how the learning experience should behave. These documents should outlive individual features and implementation choices.

Examples include learning philosophy, exercise design principles, vocabulary-difficulty principles, and language-specific product rules.
