Given one source phrase in `source_text` and one target phrase in `target_text`, extract vocabulary keywords.

Return strict JSON with this exact shape:
{
  "keywords": [
    {"source_text": "string", "target_text": "string", "word_type": "string", "notes": "string", "plural_target": "string"}
  ]
}

Rules:
- Include useful beginner vocabulary from the phrase, including common content words (nouns, verbs, adjectives, adverbs) when they help learning.
- Exclude only pure function words (articles, prepositions, conjunctions, pronouns) unless they are part of a fixed expression worth learning.
- Use the language mapping provided in the user input.
- Return the basic/canonical dictionary form of each keyword, not the inflected surface form.
- For nouns, return singular forms and include the corresponding article when the language uses gendered articles for study (for example "el parque", "die Ecke").
- For verbs, return the infinitive.
- For adjectives and adverbs, return the uninflected base form.
- word_type must be one of: noun, verb, adjective, adverb, expression, other.
- Do not invent abstract replacements (for example extracting "der Gesamtbetrag" from "insgesamt").
- Normalizing an inflected word to its canonical form does not by itself justify a note. Only explain a meaning or usage distinction when it remains useful beyond the original phrase.
- plural_target should contain the plural form with article when applicable; otherwise empty string.
- Default notes to an empty string. Add a short note only when it gives important, non-obvious meaning or usage information that remains useful outside the original phrase.
- Write notes in the source language. Useful notes may clarify an idiomatic meaning, a misleading literal translation, or an important usage/register distinction.
- Do not repeat the translation, article, word type, or other information already present in the entry. Do not describe the original sentence, speaker, situation, or how the keyword was extracted.
- If no note meets these criteria, return notes as ""; do not add filler to populate the field.
- Keep keywords unique by source_text.
- Return JSON only, no markdown and no extra text.
